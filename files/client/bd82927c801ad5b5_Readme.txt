边狱公司私服 · 使用说明（详细版）
==================================================

适用于：电脑上已经有旧的私服（有 LimbusCompany.exe、pgdata、server 这些目录）


一、这个包是什么
--------------------------------------------------
替换 4 个文件，新增 2 个启动入口，不碰你的游戏、数据库、存档、资源缓存。

  Launcher.exe                        启动器（带自动更新）
  index.json                          更新清单
  version.json                        更新清单（旧格式，兼容用）
  BepInEx\plugins\ArenaRedirect.dll   私服插件
  启动私服.cmd                        以后都从这里启动
  modsync.ps1                         人格对战内容同步器
  使用说明.txt                        就是这份

装完之后游戏本体、服务端、存档全是原来的。


二、装之前先确认三件事
--------------------------------------------------
1. 找到你的私服根目录

   就是有 LimbusCompany.exe 和 Launcher.exe 的那个文件夹。

   不确定的话：打开「此电脑」，在右上角搜索框里搜 Launcher.exe，
   找到体积 60 MB 左右的那个，右键 → 打开文件所在的位置。

2. 把游戏关掉

   游戏开着的时候 Launcher.exe 和 ArenaRedirect.dll 是占用状态，
   替换会失败。

3. 杀毒软件

   如果装完打不开，先看是不是杀软把 Launcher.exe 拦了。
   把整个私服目录加进白名单一劳永逸。


三、安装步骤
--------------------------------------------------
第 1 步
    把 zip 解压到私服根目录。

    Windows 自带解压：
      右键 zip → 全部解压缩 → 浏览 → 选中私服根目录 → 解压

    7-Zip / WinRAR：
      右键 zip → 解压到指定文件夹 → 填私服根目录

    包内没有外层文件夹，解压出来直接就是那 7 个文件。

第 2 步
    问「是否替换目标中的文件」时，选「全部替换」。

第 3 步
    双击「启动私服.cmd」

    它会依次做四件事：
      1. 检查并同步人格对战内容（第一次可能下几 MB，以后秒过）
      2. 在桌面建「边狱公司私服」图标（每次都写一遍，保证指向正确）
      3. 打开启动器
      4. 启动器自己下载 63 MB 更新

    以后每次都从这里进：
      双击桌面的「边狱公司私服」图标
      （那个图标指向的是 启动私服.cmd，不是 Launcher.exe）


四、第一次启动会看到什么
--------------------------------------------------
启动器打开后会自己检查版本。

因为线上是 launcher 0.2 / server 0.2，你本地是 0.1，
它会显示进度条，下载大约 63 MB。

  正在更新……  →  校验  →  更新完成

整个过程一两分钟，看网速。
更新完成后点「启动游戏」。

如果显示「没有需要更新的内容」但你还没更新过，
说明 index.json 没替换成功，回到第 2 步重做。


五、进游戏
--------------------------------------------------
启动器点「启动游戏」之后：

  1. 会弹一个黑色窗口，正在依次启动四个服务
     数据库 → 服务端 → 本地服务 → 资源代理
  2. 四个都就绪后，游戏窗口自动打开
  3. 游戏出来后点一下界面上的登录按钮
     （不用注册，不用输密码，不用开浏览器）
  4. 进游戏

黑色窗口不要关，关了服务就停了。


六、以后怎么更新
--------------------------------------------------
两套内容，两种更新方式，都自动。

【Arena 和启动器】
  打开启动器它会自己查、自己下。你不用管。

  ★ 提醒：仓库里的 Launcher.exe 还是旧版，启动器可能提示更新，
    跟着走就行。如果提示失败，说明作者还没上传新版，不影响游玩。

【人格对战内容】
  在 BepInEx\plugins\Lethe\mods\ 里面。
  每次双击「启动私服.cmd」（或桌面图标）时会自动检查：
    缺的补上，旧的换成新的，作者删掉的会清理掉。

  你手动关掉的 mod 不会被强行打开
  （关掉的方式：把 mod 文件夹从 mods\ 移到 mods-off\）。

  同步失败不影响启动，会直接用本地现有内容。


七、怎么关掉
--------------------------------------------------
关游戏窗口就行。后台服务会继续跑，下次启动更快。

想彻底停掉服务（比如要重启电脑前、或者端口被占了）：

  以管理员身份打开 PowerShell，进到私服目录，执行：

      .\launch.exe --stop

或者最省事：重启电脑。


八、出问题了怎么查
--------------------------------------------------
按现象对号入座：

【启动器打不开】
    杀毒软件拦了。整个目录加白名单。

【显示「更新失败」】
    网络连不上 GitHub。国内偶尔会这样。
    等几分钟再试，或者换手机热点。
    多试几次就会成功，不会损坏已有文件。

【点启动游戏，黑窗口一闪就没】
    进私服目录，空白处 Shift + 右键 → 在此处打开 PowerShell，
    输入 .\launch.exe 回车，就能看到具体报错。
    也可以看目录里的 start.log。

【卡在登录界面不动】
    四个端口被别的程序占了：5432 / 8080 / 8081 / 8082
    命令行执行：netstat -ano | findstr "5432 8080"
    看是哪一行被占用。

【游戏里有些界面是韩文】
    汉化包没覆盖到的地方，不影响玩。
    技能说明里偶尔会出现「RawDesc 没有」这类提示，
    也是同一个原因。

【更新完插件没生效】
    关掉游戏重新打开一次。
    如果还不行，看 ArenaRedirect.dll 是不是 107,520 字节。


九、存档在哪，怎么备份
--------------------------------------------------
存档在 pgdata 目录里。

想备份：把 pgdata 整个文件夹复制一份留着就行。
想恢复：把备份的 pgdata 换回去。

这一版更新不动 pgdata，不会有任何影响。


十、官服还能玩吗
--------------------------------------------------
能，互不影响。

官服直接用 Steam 启动，跟平时一样。
私服在自己的文件夹里，不碰 Steam 的游戏文件。

唯一冲突是端口：私服占用 5432 / 8080 / 8081 / 8082。
官服连的是外网，不受影响。
但同一台机器不能同时开两个私服。


十一、哪些文件不能删
--------------------------------------------------
pgdata\           存档，删了就没了
bundlecache\      游戏资源缓存，3.4 GB，删了要重新下
server\           服务端
pgsql\            数据库程序
python\           运行环境
dotnet-sdk\       运行环境
BepInEx\          mod 和私服插件
LimbusCompany.exe 游戏本体

拿不准的一律别删，一共约 17 GB，硬盘够就放着。


十二、一句话总结
--------------------------------------------------
解压 → 复制 4 个文件到私服根目录 → 全部替换 → 双击 Launcher.exe
→ 等更新完 → 点启动游戏 → 登录 → 开玩。
